# @mh_hairarrange リール一覧

[@mh_hairarrange](https://www.instagram.com/mh_hairarrange) に投稿されたリール **226本** を10カテゴリで閲覧できる簡易ビューワです。

🌐 **公開URL**: https://mh-hairarrange.github.io/mh-hairarrange-reels/

## カテゴリ (10種)

| カテゴリ | 内容 |
|---|---|
| 三つ編み 🌾 | 三つ編みアレンジ |
| くるりんぱ 🍥 | くるりんぱを使ったアレンジ |
| ポニーテール 🦄 | ポニーテール系 |
| ツイン 👯 | ツインテール系 |
| ローポニー 🌙 | 低めポニーテール |
| ハーフアップ 🌷 | ハーフアップ系 |
| 編み下ろし 🌿 | 編んで下ろすスタイル |
| イベント 🎀 | 卒園式・運動会・浴衣・クリスマスなど |
| かんたん5分 ⏰ | 30秒〜5分の時短アレンジ |
| その他 ✨ | インスタライブ・PR など |

1リールが複数カテゴリに表示されることもあります(例: 「三つ編みハーフアップ」 → 三つ編み + ハーフアップ + イベント)。

## 中身

- `index.html` — ビューワ (3画面構成: カテゴリ選択 → 一覧 → 詳細)
- `reels.json` — 表示用メタデータ
- `thumbnails/` — サムネ画像 226枚

## ローカルで見る

```bash
python3 -m http.server 8765
# → http://127.0.0.1:8765/
```
